# SWYNEX Security Assessment Report

## Task 4 — Cybersecurity Internship

This repository contains my defensive cybersecurity assessment report, documenting authorized lab exercises, security observations, evidence, risk assessments, and remediation recommendations.

## Objectives

- Document security assessment methodology.
- Analyze network traffic using Wireshark.
- Review web application security using OWASP ZAP.
- Record verified findings and recommend defensive controls.

## Tools Used

- Wireshark
- OWASP ZAP
- OWASP Juice Shop
- GitHub

## Repository Contents

- `report.md` — Main security assessment report.
- `evidence/` — Supporting screenshots and evidence.
- `findings.md` — Detailed security findings.
- `remediation.md` — Recommended fixes and defensive measures.

## Scope

All testing is limited to authorized laboratory environments. Findings should be interpreted within the limitations of the collected evidence.

## Disclaimer

This project is for educational and defensive cybersecurity purposes only. No unauthorized systems were targeted.
